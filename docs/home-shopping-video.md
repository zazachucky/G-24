# AI 가상 쇼호스트 홈쇼핑 데모 방송

**기존 제작 상태: STOPPED_SUPERSEDED_BY_APPROVED_FULL_BODY_CONCEPT.** 가상 진행자 원본과 12개 한국어 합성 음성, 짧은 시험본을 보존했다. 이 방식의 120초 본영상은 완성하지 않았다.

제작에 사용할 [스토리보드 JSON](../assets/video/home-shopping/storyboard.json)에는 12개 장면의 표시용 대사, 발음용 대사, 방송 자막, 이미지 경로, 근거 데이터와 화면 배치가 들어 있다. 인물 원본은 [host-source.png](../assets/video/home-shopping/host-source.png)다.

제작은 로컬 **SadTalker**로 원본 인물의 발화 영상을 만들고, **macOS Yuna 합성 음성**을 장면별로 배치한 다음, **Swift·AVFoundation 합성기**로 실제 상품 이미지와 방송 자막을 결합하는 방식이다. 합성기는 호스트 영상을 프레임마다 순차적으로 읽는다. 120초 호스트 영상이 없거나 중간 프레임이 누락되면 오류로 종료하며 사진이나 반복 영상으로 대체하지 않는다.

## 납품 영상 규격

- 1920×1080, 16:9, 25fps, **정확히 120초**. 장면은 10초씩 12개다.
- 최종 형식은 H.264 영상과 AAC 음성을 담은 MP4. 한국어 음성, 방송 강조 자막, 발화에 맞춘 내레이션 자막을 포함한다.
- 실사처럼 보이는 가상의 성인 진행자가 한국어로 말하며 입모양과 작은 고개 움직임을 보인다. 같은 얼굴·의상·배경을 전 구간 유지한다.
- 진행자는 상품 화면 옆에서 친근하게 설명한다. 실제 판매 상품의 사진과 상세 이미지, AI 코디 예시는 별도 삽입 화면으로 보여준다.

현재 진행자 제작 방식이 지원하는 동작은 **얼굴·입·고개의 움직임**이다. 손으로 니트를 들거나 잡아당기는 시연, 환복, 전신 동작은 생성하지 못한다. 상품 접사와 실측 표시는 확보한 실제 이미지로 편집한다. 진행자의 아이보리 재킷과 무지 상의는 진행용 의상이다. 진행자가 판매 상품을 입고 있다는 설명이나 실제 착용 경험은 넣지 않는다.

## 방송 화면

상단 왼쪽에 `GS AI LIVE`와 그 옆의 `DEMO LIVE`를 배치한다. 오른쪽에는 **`AI 가상 쇼호스트 · 데모 방송`을 처음부터 끝까지 유지한다.** 제품을 설명하는 화면에 제작 상태나 검증 보고서 문구를 노출하지 않는다.

하단 가격바에는 `SJ와니 샤이니 크리즈 캐시미어 풀오버 1종`, `메인 상의 1종 49,900원`, `판매가 · 2026.09.21 확인`을 표시한다. 코디 장면에서도 가격은 상의 한 벌의 금액이며, 하의·신발은 포함되지 않는다는 구분을 유지한다. 화면의 기본 요소는 **움직이는 진행자, 크게 보이는 상품, 간결한 방송 자막, 상품명과 가격바**다.

웜 아이보리 배경에 짙은 녹회색 글자와 청록 강조색을 사용한다. 내레이션 자막은 1080p 기준 **40px**, 실제 상품·AI 코디 라벨과 출처·데모 표시는 **24px 이상**이다. 12개 대사의 텍스트 높이와 정적 합성 배치는 확인했으며 최종 영상의 가독성 검수는 남아 있다. 화면 가장자리에는 여백을 두고 자막, 가격바, 진행자 얼굴이 겹치지 않도록 한다. 글자와 숫자는 영상 모델에 그리게 하지 않고 후반 작업에서 정확한 텍스트로 올린다.

`caption_lines`는 그 장면의 핵심 문구를 `·`로 이어 **한 줄의 24px 강조 문구**로 표시한다. 전체 대사를 표시하는 내레이션 자막은 그 아래의 별도 영역에 최대 두 줄로 배치한다. 두 자막 모두 `audio_start_s ≤ 재생 시각 < audio_end_s`인 발화 구간에만 보여준다. 내부 장면 번호·근거 경로는 시청 화면에 표시하지 않는다. 현재 합성기는 진행률이나 카운트다운을 넣지 않는다.

세 가지 화면 배치를 사용한다.

| 배치 | 진행자·상품 구성 |
| --- | --- |
| `host_product` | 왼쪽 호스트 슬롯 1000×690px, 오른쪽 상품 슬롯 774×489px. 화면 폭 기준 약 52%·40%이며 나머지는 여백이다. 상품 2장은 오른쪽에서 나란히 표시한다. |
| `product_focus` | 왼쪽 상품 슬롯 1220×542px, 오른쪽 호스트 슬롯 548×574px. 화면 폭 기준 약 64%·29%이며 접사·색상·실측 자료를 왼쪽에 크게 표시한다. 색상 4장은 2×2로 배치한다. |
| `styling` | 왼쪽 AI 코디 슬롯 744×688px, 중앙 호스트 슬롯 565×526px, 오른쪽 실제 하의·신발 슬롯은 각각 432×261px. 화면 폭 기준 약 39%·29%·23%이며 실제 상품 두 장은 세로로 쌓는다. |

위 비율은 **전체 1920px 화면 폭에 대한 슬롯 너비**이며 여백을 포함해 합이 100%가 되도록 조정한 값은 아니다. 호스트 영상과 상품 사진 모두 원본 비율을 유지한 `contain` 방식으로 슬롯 안에 표시한다. 따라서 정사각 호스트 영상은 `host_product` 슬롯 안에서 최대 690×690px로 표시되고 양옆에 여백이 생긴다. 실제 얼굴이 차지하는 폭은 소스 영상의 구도에 따라 달라진다.

상단 방송 표시 영역은 y=0~84px, 주요 사진·호스트 영역은 대체로 y=98~788px, 강조 문구는 y=798~831px, 내레이션 자막은 y=832~940px, 가격바는 y=944~1080px다. 이미지 하단의 70px 라벨 영역에서 실제 상품과 AI 코디를 구분한다. 긴 라벨은 24px의 최대 두 줄로 표시한다. 상세 이미지 `detail-10.jpg`도 현재 합성기에서는 크롭하지 않고 전체 비율을 유지한다. 원본 제품의 형태·색상·세부 무늬를 생성 모델로 다시 만들지 않는다.

## 대사와 음성

대사는 설명 자료를 읽는 말투보다 방송 진행자의 친근한 말투로 작성했다. 예를 들어 도입은 “안녕하세요! 오늘 함께 볼 상품은 에스제이와니 샤이니 크리즈 캐시미어 풀오버예요. 색상부터 코디까지 만나보세요.”로 시작한다. 숫자와 출처는 또렷하게 읽되 과도하게 구매를 재촉하지 않는다.

JSON의 `narration`은 화면 자막과 내용 확인용 원문, `narration_spoken`은 음성 합성용이다. 원문은 장면당 **55~64자**, 발음용은 **58~64자**이며 공백과 문장부호를 포함한다. 다음 발음을 사용한다.

| 원문 | 발음용 |
| --- | --- |
| 85% · 10% · 5% | 팔십오 퍼센트 · 십 퍼센트 · 오 퍼센트 |
| 63% | 육십삼 퍼센트 |
| 의류 사이즈 55 · 66 · 88 | 오오 · 육육 · 팔팔 |
| 45센티미터 · 61센티미터 | 사십오 센티미터 · 육십일 센티미터 |
| 49,900원 | 사만 구천구백 원 |

**12개 음성의 길이 실측을 완료했다.** [audio-verification.json](../assets/video/home-shopping/audio-verification.json)의 상태는 `PASS`이며 macOS Yuna, 175 words per minute, 22,050Hz로 생성했다. 가장 긴 소재 설명은 약 **8.945488초**다. 각 10초 구간의 0.45초 지점부터 배치하므로 가장 늦은 발화 종료도 해당 구간의 약 9.395488초다. 모든 음성이 9.5초 이전에 끝나고, 전체 내레이션 파일은 120초로 배치됐다. 길이를 맞추기 위해 마지막 단어를 자르지 않았다.

[렌더 계획](../assets/video/home-shopping/render-plan.json)과 자막 파일에는 측정한 발화 시각이 반영돼 있다. 장면 전환과 짧은 쉼도 각 10초 안에 넣어 전체 120초를 유지한다. 최종 MP4에서는 발화가 끝난 구간의 입모양·표정, 음성과 자막의 일치, 문장 끝의 잘림 여부를 추가 확인한다. 음성 길이 검증은 완성 영상의 립싱크나 영상 AI 기능 검증을 대신하지 않는다.

## 상품 정보 적용 기준

근거는 [메인 상품 데이터](../fixtures/main-product.json)와 [코디 구성](../fixtures/styling-looks.json)이다. 가격·리뷰·품절 여부는 **2026.09.21 확인 당시 정보**로 소개한다. 네 소개 색상이 지금 모두 주문 가능하다고 말하지 않으며 그레이 66의 일시품절 안내를 유지한다. 실측 값은 신체 치수가 아니라 의류 치수다. 리뷰에서 두께를 얇다고 평가한 비율과 제조사의 두께 안내도 서로 구분한다.

방송의 가격은 49,900원이다. [앱의 데모 설정](../fixtures/demo-config.json)에 있는 45,515원은 가상 고객의 준비된 혜택 예시이므로 방송 가격바나 음성에 넣지 않는다. 가격 장면에서는 앱의 내 혜택도 데모 예시라는 사실을 알린다. 상품에서 확인한 무료배송만 말하고, 같은 설정의 2~3영업일 배송 시뮬레이션은 방송 도착 약속으로 사용하지 않는다.

진행자의 사용 경험, 착용감 보장, 체형에 맞춘 확정 추천, 한정 수량, 마감 임박, 최저가, 실제 방송 실적은 대본에 추가하지 않는다.

## 완성본 확인

최종 MP4에서 120초 길이, 해상도, 영상·음성 코덱과 정상 재생을 확인한다. 12개 구간 모두 얼굴이 유지되는지, 한국어 음성과 입모양이 맞는지, 고개 움직임에 눈·치아·얼굴 경계가 무너지지 않는지 확인한다. 그다음 음성 잘림, 자막 시각, 가격·실측·품절 문구, AI 코디 라벨과 상시 데모 표시를 검수한다.

자막과 챕터는 합성 음성의 실측 시각으로 작성했고 완성 MP4에 대한 최종 동기 검수가 남아 있다. 이 시각은 음성 인식이나 영상 검색의 검증 결과가 아니다. 완성 파일이 생성되고 검수되기 전까지 이 문서와 JSON은 `IN_PRODUCTION`, `completed_video: false` 상태를 유지한다.

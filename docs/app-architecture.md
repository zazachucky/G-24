# GS AI LIVE 통합 앱 구현 결정

2026-09-21. 기준은 `GS_AI_LIVE_Goal_Prompt.md`, 최신 Vision·기술 환경·Handoff와 고정 Fixture다.

## 현재 자산과 선택

기존 프로젝트에는 Python 3.9 reference와 15개 도메인 테스트, 검증된 JSON·상품 이미지·3개 Lookbook·정적 미리보기가 있다. 통합 고객/PD 앱과 프레임워크 설정은 없었다. 원본 HTML은 각각 독립 상태로 동작한다. 기존 자산을 보존하고 `app/`에 통합 앱을 추가한다.

서버는 Python 표준 라이브러리, UI는 HTML/CSS/JavaScript를 사용한다. 설치 패키지·API 키·클라우드·DB가 필요 없다. 고객·Director 페이지가 동일 localhost 서버를 조회하므로 창/탭 간 상태가 일치한다. 500ms 상태 조회로 화면에 반영한다. 영구 보관과 실운영 인증은 범위 밖이며 가상 고객 선택은 시연 도구다.

## 처리 경로

고객 UI → JSON action → 고객/실행 확인 → 공통 NeedDirector → 공통 상태 조회 → Director/해당 고객 화면 반영. 실제 UI와 Fixture의 이벤트 경로는 같고 기록의 origin으로 구분한다. Director의 직접 상태 전환은 제공하지 않는다.

`GET /api/bootstrap`은 고정 상품·고객 설정·ASK·코디·미디어·체험 정책 자료를 반환한다. `GET /api/state?customer_id=customer-A`는 해당 고객의 대화·개인 장바구니·UI 상태와 공통 상태를 반환한다. 고객을 지정하지 않은 Director 상태에는 개인 대화와 장바구니가 없다. `POST /api/action`은 `run_id`를 확인하여 이전 실행의 요청이 Reset 후 새 상태를 바꾸지 않게 한다.

자유 체험은 서버 단조 시계로 진행한다. 시나리오 모드는 가상 시계를 멈춘 상태로 단계별 진행하여 68/120/121/151/421초를 재현한다. 이벤트 발생 시간에 클라이언트 타임스탬프를 사용하지 않는다. 미디어 재생 시점과 도메인 시계는 독립이다.

## 추가된 양방향 데이터 연동

연동 필드·Action·집계 범위는 [cross-screen-contract.md](cross-screen-contract.md)에 정의한다. 고객의 실제 이벤트와 서버가 검증한 UI 값 변경을 같은 수신 경로에 기록하고, Director에 익명 범주·고정 가상 고객 사용 상태를 전달한다. 선택 변경·코디 연결 SKU·ASK 분류·응답 실패 대체·미디어 오류도 이 경로를 사용한다. 실제 이용 집계는 현재 상품 UI 이벤트만 포함하며 Fixture와 분리한다.

공용 안내는 Director의 게시/회수 Action으로 같은 서버에 저장한다. 고객이 안내를 화면에 표시하면 idempotent 표시 확인을 전송한다. private 대화와 별도로 저장하므로 다른 고객 대화에 질문이 복제되지 않는다. 게시 재시도에는 같은 안내 ID를 사용한다.

접속은 5초 heartbeat와 15초 서버 단조 시계 lease로 판정하며 virtual clock 조작에 영향을 받지 않는다. 승인 전후 실제 이용은 승인 수신 당시 이벤트 순서로 구분하므로 시연 시각이 같아도 순서가 보존된다. 프로세스 메모리 저장, localhost 범위, 준비 답변 사용은 유지한다.

첨부 화면의 다중 관심 트렌드·TOP 5·인사이트는 `received_at`으로 기록한 서버 실제 수신 경과초를 사용한다. 기존 이벤트 `at`과 승인·TTL은 가상 도메인 시계를 유지한다. 실제 UI만 현재 방송·상품으로 한정한 뒤 `experience_metrics.py`의 순수 집계 함수에 전달한다. 질문은 enum 주제와 고정 대표 문구로 공개하며 원문을 공개 집계에 넣지 않는다. 구매 체험 완료율은 분자·분모를 명시하고 기존 고정 Simulation과 분리한다.

공개 댓글은 고객이 별도 공개 입력에 제출한 내용만 저장한다. 공개 API는 최근 100개와 누적 건수를 분리하고 고객 영상에는 최근 3개를 표시한다. 개인 ASK를 자동 변환하지 않으며 게시 재시도는 실행·고객·댓글 ID로 중복을 막는다. HTML은 화면에 텍스트로 출력한다.

장바구니는 고객별 메모리에 보관하며 서버에서 실제 옵션 스냅샷과 수량 1~10을 검증한다. 동일 옵션 추가는 합산하고 요청 ID를 보존해 응답 유실 재시도를 처리한다. checkout의 옵션·수량을 기록하여 다른 탭이 뒤에 추가한 수량을 완료 시 함께 삭제하지 않는다. 장바구니 합계와 준비 혜택 합계를 구분하고 실제 주문·결제는 생성하지 않는다.

사이즈 프로필은 고객별 private 상태에 키·평소 사이즈·반사이즈 여부·선호 핏·보유 의류 가슴단면을 저장한다. 비교 함수는 실제 상품 실측표에서 입력한 의류 폭 이상인 최소 옵션을 찾고, 여유 핏과 판매자 반사이즈 안내를 명시한 규칙으로 적용한다. 키만으로 체형이나 맞음새를 추정하지 않는다. 범위를 넘으면 추천 숫자를 만들지 않고 직접 확인을 안내한다. 기본 프로필은 기존 66 안내를 유지하며 추천과 현재 구매 선택은 별도다. 공개 로그에는 입력값 없이 변경 이벤트만 남긴다.

LIVE 퇴장 상태는 고객·상품별 `sessionStorage`에 저장한다. 해당 탭의 presence lease만 종료하고 heartbeat를 멈추므로 같은 고객의 다른 탭은 유지된다. 공유는 상품 공개 URL의 클립보드 복사이며 권한 실패 시 직접 복사 UI로 대체한다. 외부 메시지 전송은 없다.

## 콘텐츠와 미디어

상품은 `1084192893` 고정 스냅샷을 사용한다. 실제 GS SHOP 페이지 조회는 런타임 의존성이 아니다. 가상 고객·준비 혜택·배송 Mock·AI 코디·성과 Simulation 라벨을 유지한다. ASK는 PREPARED이며 외부 LLM 호출이 없다. 응답 지연/오류 검사는 로컬 어댑터 실패 주입으로 수행한다.

원본 MD·HTML의 복사본과 해시는 `requirements/reference/asset-register.json`에 기록한다. 다른 상품의 참고 MP4는 `assets/video/reference/core-authentic-cardigan.mp4`로 복사했다. 원본을 편집하지 않았고 SHA-256은 `b945e14a8b71ce82056c43eff8af59095b32e7a5289a8d7c4abf736e15c64d3b`다. 실제 57.90초·720×1280·H.264/AAC이며 전체 영상·음성 스트림 디코딩을 확인했다.

현재 영상 질문은 직접 확인한 참고 화면 7개 구간과 기존 120초 상품 설명 샘플의 제작 대본 12개 장면을 조회한다. 참고 영상에는 현재 상품 근거 사용을 금지하는 자산 속성을 유지한다. 로컬 Whisper 결과는 오인식을 포함한 초안으로 보관하고 답변 근거에 자동 채택하지 않는다. 브라우저는 선택한 자산과 실제 재생 위치를 저장한 뒤 질문하며, 답변의 근거 장면 이동과 원래 영상·위치·재생 상태 복귀를 지원한다. 임의 영상 자동 분석·실시간 방송 인입·외부 영상 이해 모델 호출은 구현한 기능으로 표시하지 않는다.

## 검증 전략

기존 상품/자산 검증과 도메인 회귀 검사에 서비스 테스트·HTTP 통합·실제 Chrome UI 검수를 추가한다. 고객 A/B/C와 Director를 다른 브라우저 페이지로 열어 같은 실행 상태를 확인한다. 브라우저 상호작용, 3회 시나리오, 오류 대체, 실제 MP4 재생/디코딩/탐색, 세로/가로와 좁은 뷰포트 화면을 증거로 남긴다. 단위 PASS를 UI PASS로 대신하지 않는다.

브라우저 검사 도구는 Node 내장 WebSocket과 Chrome DevTools Protocol을 사용하므로 npm 패키지가 필요 없다. 앱 실행에는 Node가 필요 없다. 플랫폼 범위는 로컬 Chrome이며 실제 휴대폰/다중 기기·실운영 부하는 별도 검증 대상이다.

추가 검사는 장바구니·댓글의 불확실한 응답 재시도, 같은 고객의 다중 탭과 checkout 수량 경합, 고객 격리, 공개 댓글 누적/최근 목록 차이, 실제 버튼 노출의 중복 방지, 미디어 맥락 변경을 포함한다. Director 검사 서버에서만 수신 단조 시계를 제어해 5분·30분 경계를 재현한다. 실행 명령과 최종 수치는 [실행 안내](run-demo.md), [검수 결과](app-verification.md), [첨부 화면 검토](experience-completion-review.md)를 기준으로 한다.

# 고객 모바일 검수 · 2026-09-22

## 자료/범위

최신 모바일 요구사항을 우선 적용했습니다. 바닐라 HTML/CSS/JavaScript + 기존 Node 정적 서버를 유지했고 외부 의존성은 추가하지 않았습니다. 기존 상품·코디·후보 사진 7개는 제공 HTML에서 바이트 그대로 추출했습니다. 원본 HTML과 개선 전 실행 화면은 `reference/`에 보존돼 있습니다. 이후 첨부 이미지의 누락 기능 보강으로 Director 본문도 공통 상태에 연결했으며, 추가 검수는 [기능 대조표](feature-gap-audit.md)를 참고하세요.

## 정직한 경계

- 실제 상품 데이터는 제공 자료 시점 기준입니다. 최신 판매 여부·가격·재고·링크 도착 페이지는 원격 GS SHOP에서 검증하지 않았습니다. 후보 링크는 자료의 URL을 재사용합니다.
- 배송 영업일 2~3일은 가상 예시이며 주문 보장이 아닙니다. 회원/스타일/혜택 조건도 가상 고객 시나리오입니다.
- 집단 8→26, 승인 대상 33, 결과 지표는 Simulation입니다. 실제 시청자 33명을 생성하거나 원격 전송하지 않습니다. B/C는 기존 공통 상태의 제외 fixture입니다.
- 같은 origin의 브라우저 탭 연결만 지원합니다. 이후 연동 보강에서 IndexedDB 트랜잭션으로 동시 탭 쓰기 충돌을 처리했습니다([연동 검수](data-sync-audit.md)). 서버 transport와 다중 기기는 여전히 범위 밖입니다.
- Chrome viewport 검수는 실제 스마트폰/Safari 테스트가 아닙니다. 물리 키보드/IME, 노치·안전 영역, 화면 확대 접근성, 저속망/실제 모바일 미디어 정책은 실기기 검수가 필요합니다.
- 실제 AI와 영상 분석을 호출하지 않습니다. 신발 사이즈, 실측값, 모델 착용 정보는 생성하지 않습니다.

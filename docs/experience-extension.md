# 첨부 화면 기준 기능 보완

2026-09-21. 사용자 목표: “여기 있는 화면들 중에 빠진 기능 있으면 추가해서 진행해줘”. 기준은 첨부 Customer Experience 5개 영역과 Director Experience 3개 영역이다. 이미지의 배치·동작을 현재 로컬 통합 앱으로 연결하며, 기존 상품 스냅샷과 확정 Need 규칙을 이미지 속 예시 숫자로 바꾸지 않는다.

## 고객 화면

| 영역 | 추가한 기능 | 동작·데이터 경계 |
| --- | --- | --- |
| LIVE 시청 | 공유, 개인 장바구니, 나가기·재입장 | 공유는 공개 상품 URL 복사. 복사 권한이 없으면 주소 직접 복사. 나가기는 해당 탭만 종료하고 다른 탭·방송은 유지 |
| 공개 댓글 | 별도 입력, 방송 위 최근 댓글, Director 전달 | 고객이 공개로 제출한 글만 공용. ASK 개인 질문은 자동 게시하지 않음 |
| ASK LIVE | 답변 안의 선택형 리뷰 막대와 전체 리뷰 이동 | 실제 63/35/2% 등 스냅샷 집계. 문항 합계 99%를 보정하지 않음 |
| 방송 내용 ASK | 요약·현재 장면 설명·장면 찾기·해당 위치로 이동·원래 위치 복귀 | 코어어센틱 참고 영상의 검수한 화면 자막·모습 7개 구간과 상품 설명 샘플 대본 12개 장면을 자산별 분리 |
| 내 사이즈 | 개인 사이즈 기준 입력·저장, 실측 비교 제안, 결과 내 55/66/77/88 선택, 리뷰 근거 카드, 선택값 구매 연결 | 기본 추천 66과 사용자의 선택은 별도. 반사이즈·보유 의류 가슴단면·선호 핏을 명시적 규칙으로 비교. 87%는 전체 선택형 사이즈 평가이며 비슷한 체형 만족률·개별 후기 원문이 아님 |
| 내 혜택 | GS Pay·할부·배송 조건 카드와 상세 이동 | 기존 45,515원 예시를 유지. 확인되지 않은 무이자·추가 적립·당일 배송을 보장하지 않음 |
| 코디 추천 | 3 Look 이미지 썸네일, 전체 상품 7개 목록, 코디 복귀 | 확정 상의 1·하의 3·신발 3의 실제 SKU. AI 이미지와 상품 카드를 구분 |
| 장바구니 | 담기·수량 변경·삭제·상품별 구매 체험·새로고침 유지 | 가상 고객별 저장, 옵션당 1~10개. 품절/미확인 옵션은 담기 불가. 실제 주문 없음 |

구매 체험에는 카트에서 선택한 수량이 반영된다. 상품가 합계는 49,900원×수량, 준비된 혜택가 합계는 45,515원×수량으로 구분한다. 같은 옵션을 다른 탭에서 더 담아도 완료 시 checkout 당시 수량만 차감한다. Reset은 댓글·카트·옵션·대화·집계를 초기화한다.

개인 사이즈 기준은 `profile_update`로 저장하며 같은 고객의 새로고침·재입장에 유지된다. Director와 다른 고객에게 입력값을 전달하지 않는다. 입력은 키(선택, 140~200cm), 평소 사이즈, 반사이즈 여부, 선호 핏, 잘 맞는 보유 의류의 가슴단면(선택, 30~80cm)이다. 가슴단면은 신체 둘레가 아니다. 상품 실측의 같거나 큰 최소 옵션을 비교하고, 여유 있는 핏은 한 단계 큰 옵션을 제안하는 데모 규칙이다. 반사이즈는 상품 안내대로 상위 옵션을 최소 기준으로 삼는다. 88을 넘는 조건은 없는 사이즈를 만들지 않고 직접 확인을 안내한다. 키는 의류 총길이 참고에만 사용한다.

저장은 추천 근거만 바꾸며 구매 옵션을 자동 선택하지 않는다. 체형 측정·학습 모델·개인별 맞음새 보장이나 유사 체형 리뷰 비율을 제공하는 기능은 아니다.

| 적용 전후 실제 지표 | 사이즈 질문, 상품 상세 조회, 구매 체험 완료율 | 승인 수신 순서로 전후 분리. 각 구간 참여 고객 중 완료 고객의 분자·분모 표시 |

전후 실제 값은 누적 관찰 기간과 참여 고객이 다르므로 인과 효과·실제 구매 전환율로 해석하지 않는다. 기존 실제 이용 4개 행과 고정 `Prototype Simulation` 성과 카드 3개는 함께 유지한다.

새 트렌드의 시간은 서버가 실제 요청을 받은 실행 경과초다. 기존 Need의 30초 감지·60초 집단 분석·승인 TTL은 시연 가상 시계를 그대로 사용한다. Demo Control의 +30초나 영상 탐색으로 실제 질문의 수신 시간을 조작하지 않는다.

## 영상 근거

원본 참고 MP4는 변경하지 않았다. 실제 음성에 로컬 Whisper base·small을 실행했으나 고유명사·겹친 발화의 오인식이 있어 전사는 초안으로 보존했다. 앱 답변은 직접 확인한 14개 원본 프레임에서 채택한 7개 장면 근거를 사용한다. 원시 전사만으로 착용 사이즈·상품 함량·현재 가격을 단정하지 않는다.

- 참고 영상: 코어어센틱 가디건, 약 57.9초, 현재 SJ와니 상품과 다름. 확인 구간 밖이나 미확인 정보는 확인 불가를 안내한다.
- 상품 설명 샘플: 기존 120초 합성 음성 영상. 12개 제작 대본 장면의 검색이며 실제 방송 ASR 결과가 아니다.
- 해당 장면 이동은 실제 MP4 재생 위치를 바꾸고, 이전 자산·시각·재생/정지 상태로 복귀할 수 있다. 영상 시계와 Need 시계는 별개다.
- 근거: [영상 지식 데이터](../fixtures/video-knowledge.json), [원본·전사·화면 검수 기록](../assets/video/reference/transcript-review.json), [브라우저 검수](evidence/video-experience-verification.json).

실시간 방송 인입, 임의의 새 영상 자동 분석, 실제 결제·재고 예약·배송, 외부 쇼호스트 송출은 이 로컬 프로토타입에서 구현한 기능으로 표시하지 않는다.

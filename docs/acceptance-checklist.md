## 시연 순서

1. Reset Demo를 실행하고 김지수(A)와 비대상 고객(B), 거절 검사용 고객(C)을 준비한다.
2. 이미지 기반 LIVE 화면에서 후기·두께·혜택·사이즈·코디를 확인한다.
3. 세로·가로 전환 후 같은 대화와 상품 상태가 유지되는지 확인한다.
4. `Start Need Demo`에서 자유 체험의 이벤트·승인 상태와 가상 시계를 초기화한다. Fixture를 68초까지 순서대로 재생해 A의 선제 제안과 C의 거절을 확인한다. 정적 상품·프로필은 유지한다.
5. `Trigger Director Spike`는 미처리 이벤트만 120초까지 같은 집계 경로로 이어 재생한다. 이미 처리한 0초부터의 이벤트를 다시 입력하거나 시계를 뒤로 돌리지 않는다.
6. PD가 근거와 제안을 확인한다. 승인 전 A/B의 PD 강조는 없다.
7. APP Action 승인 후 A의 내 사이즈 버튼 강조, B/C 미적용을 확인한다.
8. 쇼호스트 완료 상태와 시뮬레이션 Result를 확인한다.

발표용 시계는 실제 시각과 분리한 가상 시계를 쓴다. 중간 상태로 이동하는 컨트롤은 개발자 화면에만 노출한다.
Result 바로 이동은 APP 승인이 있고 가상 시계를 승인 후 30초 이상으로 진행한 경우만 허용한다.
쇼호스트 전달만으로 Result를 열지 않으며, 승인 없이 성과가 발생한 것처럼 표시하지 않는다.

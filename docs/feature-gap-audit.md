# 첨부 이미지 기능 대조 · 2026-09-22

기준: 고객 경험 5개 영역 / Director 경험 3개 영역이 있는 첨부 이미지와 현재 실행 코드 비교. 디자인 전체 교체가 아니라 누락 기능을 추가했습니다. 이미지 내 예시 수치가 기존 확정 명세와 충돌하는 경우 확정 명세를 유지합니다.

## 데이터 경계

- 이미지의 55/92%, 79,900원, 즉시할인/카드할인/적립금 예시를 실제 상품 데이터로 채택하지 않았습니다. 기존 확정값 **66 / 87% / 49,900 − 2,495 − 1,890 = 45,515원**을 유지합니다.
- 추가 적립률, 카드사 무이자 조건, 실제 배송 예정일은 미제공/미연동으로 안내하며 계산에 더하지 않습니다. 공식 상품 링크는 제공 자료의 URL이며 최신 재고·판매 상태는 별도 확인이 필요합니다.
- 영상 내용 질문, 모델 착용 사이즈, 유사 체형 매칭, 실제 AI/실시간 방송/주문/결제/배송 API는 연결하지 않았습니다. 영상 AI는 기존 TODO/미검증입니다.
- 실제 로컬 질문 집계와 고객 A의 행동/수락/거절/PD 승인만 현재 UI 이벤트 기반입니다. 33명 대상, 기타 운영 KPI, 추이 샘플, 전후 성과는 Simulation입니다.
- 장바구니는 현재 탭 메모리의 데모이며 새로고침/나가기에 보존되지 않습니다. 안내문에 명시했습니다. 실제 GS SHOP 장바구니는 수정하지 않습니다.

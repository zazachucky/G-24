## 가격·판매 상태 확인 방식

- `renderJson.prd.exposPrdNm`, `prdImgL1`/`imgInfo`, `renderJson.pmo.prc.minPrc`, `salePrc`, `cpnDcAmt`를 사용했다. JSON에는 표시가와 할인 전 페이지 판매가를 함께 남겼다. 개인 카드·회원 혜택은 더하지 않았다.
- 최종 후보 14개 모두 공개 페이지의 `renderJson.prd.prdSaleSt`가 `Y`였다. 이는 페이지 판매 상태이며 실제 결제 성공이나 특정 사이즈 재고를 검증한 것은 아니다.
- `attrTypList`의 `stockFlg=Y`는 HTML의 `(일시품절)` 표기와 대응한다. 이름 때문에 Y를 재고 있음으로 해석하지 않는다. 원본값과 `page_sold_out`을 함께 저장했다.
- 일부 페이지는 JSON-LD `availability=InStock`를 내보내면서 실제 `prdSaleSt=N`이었다. 따라서 JSON-LD만으로 상품을 선정하지 않았다. 1061166032 헤니트 데님, 1102381103 옷자락 스커트, 1121878867 고세 메리제인은 최종 후보에서 제외했다.
- 가격과 재고는 시점에 따라 달라진다. 데모 카드 가격에는 기준일을 표시하고 구매 관련 동작은 실제 상품 상세 페이지 열기로 제한한다. 하의·신발 사이즈를 자동 선택하거나 메인 상의 66을 전파하지 않는다.

- CASUAL: 청색 데님의 실제 너비와 스니커즈의 메쉬·베이지 포인트를 보존한다.

# 착용·시연형 홈쇼핑 영상

사용자가 승인한 [실사형 시안](../assets/video/reference-review/home-shopping-concept-v1.png)을 기준으로 가상 인물의 착용 시연, 소매 접사, 전신 코디를 제작한다. 참고 영상의 구도는 세로 9:16이다. 소개할 상품은 기존 fixture의 **SJ와니 샤이니 크리즈 캐시미어 풀오버**이며, 참고 영상에 등장한 다른 상품의 가디건으로 바꾸지 않는다.

현재 상태는 **영상 생성 및 동작 검수 진행 중**이다. 입력 이미지와 음성 준비가 영상 완성을 뜻하지 않는다. 기존 얼굴 중심 SadTalker 제작은 중단했고 산출물은 보존했다. 해당 시험본으로 승인된 손·착용·전신 시연을 충족했다고 처리하지 않는다.

처음 계획한 데모 길이는 120초다. 먼저 세 장면을 연결하는 약 24초 검수본으로 동작과 화질을 확인한다. 짧은 검수본을 120초 완성본으로 표시하지 않는다. 원본 프레임을 보간하는 경우 실제 유효 구간에 맞춰 검수본 길이는 더 짧아질 수 있다.

내레이션은 macOS Yuna로 합성한 한국어 음성이다. 세 문장은 각각 약 5.77초, 5.58초, 5.64초다. 자막 시점은 측정한 음성 길이를 기준으로 하며 ASR 출력이 아니다. 영상 모델의 인물 입모양과 음성의 동기는 아직 검증하지 않았다.

## 로컬 영상 생성

1. SVD 이미지 기반 영상 생성: 공식 모델 가중치를 검증하고 MPS 환경에 준비했다. fp16 UNet에서 비정상값이 생겨 bf16으로 변경했다. 공간 attention의 독립 배치를 나눠 메모리 사용량을 줄였다. 실제 착용 장면 생성은 진행 중이다. SVD에는 대사나 정확한 손동작을 지시하는 텍스트 제어가 없으므로 결과 영상을 직접 검수한다.
2. LTX-2.3 MLX: 텍스트로 동작을 지시할 수 있는 대안을 별도로 준비 중이다. 모델 다운로드 완료와 실제 추론 성공은 별개로 기록한다. 설치나 CLI 실행만으로 영상 생성 성공을 선언하지 않는다.

도구 설치와 모델 가중치는 `tools-local/` 아래에 격리했다. 재현 명령과 진단 기록은 해당 폴더의 `I2V-SETUP.md`, `ltx-setup.md`를 참고한다.

## 합성과 검수

- 납품 컨테이너는 H.264/AAC MP4, 세로 720×1280, 24fps다. 낮은 해상도로 생성된 장면을 확대하는 경우 원본 해상도를 메타데이터에 별도로 기록한다.
- 합성기는 존재하는 실제 영상만 읽는다. 필요한 원본 길이가 부족하면 실패하며, 반복 재생이나 마지막 프레임 정지로 길이를 채우지 않는다.
- 장면별 0.5~1.0배 재생을 명시할 수 있다. CPU 동작 보간은 선택 사항이고 적용 여부를 기록한다. 보간으로 손·옷 윤곽이 일그러지는지 확인한 뒤 채택한다.
- 상단에 `AI 가상인물 · 데모`, 하단에 상품명과 **상의 1종 49,900원**, 2026.09.21 확인 자료, 하의·신발 별도를 표시한다.
- 손·팔·몸통의 동작이 배경 이동과 구분되는지 확인한다. 얼굴, 손가락, 손목, 옷과 손의 접촉, 발의 바닥 접촉을 검수한다.
- 원본 상품의 목선·소매·색상·밑단이 유지되는지 확인한다. AI 착용 모습으로 실제 핏·촉감·착용 경험을 보장하지 않는다.
- 최종 파일의 재생 길이·프레임 수·음성·자막 시점을 확인한 뒤 링크와 완료 상태를 갱신한다.

고객 앱의 영상 AI는 아직 연결하지 않았다. 이번 MP4의 재생 성공과 음성 인식·의미 검색·요약 품질 검수는 별도 항목이다.

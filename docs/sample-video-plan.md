# 합성 쇼호스트 샘플 영상 제작안

권장 길이는 **2분**이다. 상품·소재·색상·리뷰·사이즈에 1분, 코디 3개에 30초, 가격·배송·마무리에 30초를 배분한다. 사용자가 요청한 형식은 **쇼호스트가 직접 움직이며 설명하고, 옆에 상품 자료를 보여주는 영상**이다.

현재 산출물은 [제작용 대본·스토리보드](../assets/video/sample-live/storyboard.json)다. 완성 영상이나 생성된 호스트 자산이 아니다. 실제 제작에는 한국어 발화, 입모양, 시선, 작은 손동작을 표현하는 합성 쇼호스트 영상이 필요하다. 상품 사진만 넘기는 슬라이드는 최종 형식에 해당하지 않는다.

## 구성

- 화면비: 16:9.
- 길이: 목표 120초. 계획상 10초 장면 12개를 순서대로 연결한다. 아래 시각은 아직 측정하지 않은 편집 초안이다.
- 호스트: 사용자가 최종 선택한 실사형 가상 성인 인물. 실제 상품 사진 속 모델과 구분되며, 중립적인 무지 의상으로 상품 화면을 소개한다. 일러스트 스타일은 선택되지 않았다.
- 상품 자료: 확보한 실제 상품 이미지, 실측 사이즈표, 사전 생성한 AI 코디 예시, 실제 추천 상품 이미지.
- 내레이션: 장면당 53~64자. 실제 음성 길이를 확인한 뒤 전체 120초를 목표로 컷 길이를 조정한다. 발음을 부자연스럽게 빠르게 만들지 않는다.
- 자막: 장면당 짧은 2~3줄. 실제 상품 정보와 데모 예시는 각각 출처 표시를 유지한다.

각 장면의 전체 내레이션, 자막, 이미지 경로, 근거 데이터 경로, 호스트 동작 지시는 `storyboard.json`에 있다. `images`는 모두 호스트 옆에 넣을 자료이며 호스트 영상 파일이 아니다. `host_delivery`는 해당 장면의 발화·동작 연출, `product_visual`은 자료 화면 배치다. 복사해서 쓸 수 있는 [장면별 제작 지시](../assets/video/sample-live/scene-prompts.md)와 [통합 지시서](sample-video-production-brief.md)도 함께 제공한다.

## 계속 표시할 문구

전 구간에 `데모용 샘플 영상 · 실제 방송 아님`과 `합성 쇼호스트`를 유지한다. 개별 장면에는 다음 표시를 더한다.

- 코디 3장면: `AI 코디 예시`. 생성 이미지는 크게, 실제 추천 하의·신발 이미지는 별도 영역에 표시한다.
- 가상 고객 안내: `가상 고객 예시`. 그레이 66이 확인 당시 일시품절이라는 사실을 화면과 음성에서 알린다.
- 가격 장면: 실제 판매가 49,900원에는 확인일을 붙이고, 45,515원은 `데모 혜택 예시`로 표시한다.
- 배송 장면: 2~3영업일 도착은 `배송 시뮬레이션`. 무료배송만 실제 상품 안내에서 확인한 값이다.

상품 데이터 확인일은 **2026.09.21**이다. 소개 색상이 있다고 그 색상의 모든 사이즈를 지금 살 수 있다고 표현하지 않는다. 합성 호스트가 실제 판매 상의를 입고 있다는 검증도 없으므로, 호스트 의상이나 몸짓을 실물 착용 증거로 사용하지 않는다. 체형에 맞는 사이즈나 모델 착용 사이즈를 추론하지 않는다.

## 제작 방식

먼저 한 장면으로 한국어 발화·입모양·호스트 움직임의 품질과 실제 발화 길이를 확인한다. 같은 호스트와 의상, 배경을 유지해 12개 장면을 제작한 뒤 실제 상품 이미지와 자막을 후반 작업으로 넣는다. 화면 내 문자와 가격을 영상 생성 모델에 직접 그리게 하지 않고, 검증한 텍스트를 별도 레이어로 올린다.

`detail-10.jpg`는 긴 세로 이미지다. 목선과 소매의 패널을 각각 비율 유지 크롭해 보여주며 전체를 가로로 늘이지 않는다. 사이즈표는 숫자가 읽히도록 크게 배치하고 66 열의 값을 자막 카드로 보완한다. 전환 효과는 편집된 장면 길이 안에서 처리한다.

이 제작안은 [실제 상품 데이터](../fixtures/main-product.json), [데모 고객·혜택·배송 설정](../fixtures/demo-config.json), [확정 코디 3개](../fixtures/styling-looks.json)를 근거로 한다. 추가 상품 효능, 착용 경험, 방송 실적은 넣지 않았다.

## 영상 완성 후 확인할 항목

완성 파일의 총길이가 목표 120초에 맞는지 확인하고, 각 장면의 음성 잘림, 입모양, 손동작, 자막 가독성, 표시문구 유지, 실제 상품과 AI 코디 이미지 구분을 검수한다. 음성 합성 도구가 숫자를 읽는 시간이 글자 수 예상과 다를 수 있으므로 실제 음성을 기준으로 컷 길이와 문장 사이 쉼을 조정한다.

장면 시작 시각은 SRT/VTT와 챕터의 기준으로 사용할 수 있다. 다만 이것은 **사전에 작성한 대본의 시각 정보**다. 완성 영상을 대상으로 요약·영상 검색·북마크 기능을 실제 실행하고 결과를 확인하기 전에는 Video AI 검증 통과로 취급하지 않는다.

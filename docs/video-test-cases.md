# 120초 테스트 영상 검수 정의

대상 파일은 `assets/video/test-live/gs-ai-live-test-120s.mp4`다. 실제 상품 이미지·한국어 합성 음성·자막으로 제작하는 기능 검증용 영상이며 실사 쇼호스트가 진행하는 완성본이나 실제 방송이 아니다.

이 문서와 [검수 Fixture](../fixtures/video-test-cases.json)는 **검수 정의만 작성한 상태**다. 모든 사례는 `NOT_RUN`이다. 플레이어, ASR, 요약, 장면 검색, 북마크를 실행했다는 뜻이 아니며 PASS 결과가 없다.

## 정답과 실행 결과의 분리

- 장면 구간·화면 내용은 [render-plan.json](../assets/video/test-live/render-plan.json)을 기준으로 정했다.
- 발화 정답은 [reference-transcript.json](../assets/video/test-live/reference-transcript.json)의 `script_reference_not_asr` 자료다. 이 파일은 준비한 대본과 배치한 음성 클립 길이를 기록한 것이며 실제 음성 인식 결과가 아니다.
- ASR 검수에는 최종 MP4에서 추출한 실제 음성만 입력한다. 대본·자막·정답 JSON을 ASR 입력이나 보정 프롬프트로 제공하지 않는다.
- 영상 AI 검수에는 실제 MP4 또는 실제 실행한 ASR·영상 분석 결과를 입력한다. 정답 대본을 돌려주는 준비 기능은 AI 실행 성공으로 기록하지 않는다.
- 정적 목록에서 구간을 이동하는 기능과 자연어로 장면을 검색하는 AI 기능은 별도로 판정한다. 플레이어 이동 성공만으로 장면 검색을 PASS 처리하지 않는다.

시각은 MP4 시작을 0초로 한다. 장면 구간은 시작 포함·끝 제외이며 마지막 영상 끝은 120초다. Render plan의 음성 시작은 각 장면 시작 후 0.45초다. 이것은 계획값이며 최종 음영상 동기는 실제 파일로 확인해야 한다.

허용오차는 이번 데모의 검사 기준으로 정한 값이다. 이미 검증된 성능·서비스 보장값이 아니다. 시간 오차와 정답 내용 오류를 상쇄하지 않는다. 올바른 시각을 찾았더라도 금액·재고·출처를 잘못 설명하면 해당 사례는 통과할 수 없다.

V03에서 쉼표·공백·한글 수사 및 `cm`/`센티미터` 같은 동등한 표기는 허용한다. 문장을 ASR이 여러 세그먼트로 나누면 해당 발화의 첫 시작과 마지막 종료를 합쳐 비교한다. `일시품절`, `가상 고객`, `데모`, `실제 조회가 아님`의 의미를 빠뜨리는 것은 단순 표기 차이가 아니다.

V10은 같은 `request_id=video-bookmark-office-001` 저장 요청을 다시 보내도 북마크가 하나여야 한다. 자연어 검색 결과가 실제로 나온 것인지와 저장·이동 동작이 정확한지를 각각 기록한다. 정적 북마크를 잘 눌렀다는 이유로 AI 검색까지 통과시키지 않는다.

## 전체 요약 정답의 핵심

다음은 AI 결과가 아니라 **대본·렌더 계획에서 작성한 평가 정답**이다.

1. SJ와니 캐시미어 풀오버를 소개하는 기능 검증용 샘플이다.
2. 확인 판매가는 **49,900원**, 가상 고객의 데모 혜택 예시는 **45,515원**이다. 실제 결제 적용을 보장하지 않는다.
3. **66의 의류 실측은 가슴단면 45cm·총길이 61cm**다. 사람의 신체 치수나 모델의 착용 사이즈가 아니다.
4. 가상 고객에게 66을 먼저 안내하지만 **그레이 66은 확인 당시 일시품절**이다. 전체 색상 재고나 현재 실시간 재고로 일반화하지 않는다.
5. **구매자 리뷰는 얇아요 63%, 제조사 가이드는 약간 두꺼움**으로 평가 출처가 다르다. 하나의 일치된 사실처럼 합치지 않는다.
6. 무료배송은 상품 안내이고 **주문 후 2~3영업일 도착은 배송 시뮬레이션**이다. 실제 조회·배송 확약이 아니다.
7. 출근·약속·주말의 세 코디를 소개한다. AI 코디 예시와 실제 상품 이미지를 구분한다.

음성에는 없는 정보도 구분한다. 예를 들어 두께 리뷰의 35%·2%는 화면 자막에 있지만 해당 장면 내레이션에는 63%만 나온다. 음성만 분석한 결과에서 35%·2%를 실제 ASR이 인식했다고 기록하면 안 된다. 모델 착용 사이즈·키·체중·실착 경험은 정답에 없으며 추정해 추가하지 않는다.

## 실행 결과를 남기는 방법

각 사례의 `execution`에 실행 시각, 실제 출력, 근거 파일 경로를 기록한다. 현재 값은 `NOT_RUN`, 실행 시각·출력은 `null`, 근거 파일은 빈 배열이다.

- 재생·이동: 미디어 메타데이터, 실제 currentTime, 화면 캡처 또는 재생 기록.
- ASR: 모델/엔진과 설정, 원시 인식 출력, 단어·구간 타임스탬프, 실제 사용한 음성 파일.
- 요약·검색: 실제 입력 질문, 모델/엔진과 설정, 원시 출력, 선택 구간 및 평가 결과.
- 북마크: 저장한 구간, 요청 ID, 저장 결과, 클릭 후 currentTime.

실행하지 않으면 `NOT_RUN`을 유지한다. 실행 후 필수 기대값이 모두 충족되어야 `PASS`다. 일부만 충족하면 `PARTIAL`, 핵심 동작·사실 조건이 실패하면 `FAIL`로 기록하고 원인을 남긴다. Main Demo에 포함할 영상 AI 기능은 실제 실행해 PASS를 받은 기능으로 한정한다. 이 문서를 만들었다는 사실이나 MP4가 존재한다는 사실만으로 상태를 바꾸지 않는다.

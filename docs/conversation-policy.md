# 대화·고객 화면 결정 사항

결정일: 2026-09-21. 미결정 항목을 구현 가능한 기본값으로 확정한 문서다.

## 공개 범위

- 운영자 메시지는 같은 방송의 모든 데모 고객에게 보인다.
- 입력창은 `AI에게 질문`으로 표시한다. 고객 질문과 ASK LIVE 답변은 해당 고객에게만 보인다.
- 개인별 답변은 공용 운영자 메시지와 같은 타임라인에 배치하되 고객·방송·상품별 Conversation State를 분리한다.
- SYSTEM 메시지는 기본적으로 개인에게만 보인다. 공용 안내는 별도로 `visibility=broadcast`를 지정한다.
- PD에게는 집계값과 고객 식별자를 제거한 대표 질문만 표시한다. 개인 프로필·주소·개인 혜택 답변은 표시하지 않는다.

메시지는 `message_id`, `conversation_id`, `broadcast_id`, `product_id`, `actor`, `visibility`,
`customer_id`(개인 메시지), `request_id`, `text`, `source_refs`, `created_at`, `provenance`를 가진다.
공용 메시지의 개인 식별자 값은 비워 둔다.

## ASK LIVE와 Direct Result

P0 답변 Intent는 후기·두께·색상·배송으로 유지한다. 준비 답변은 `fixtures/ask-live.json`에 있다.
사이즈·혜택·코디 질문은 기존 Direct Result로 연결한다. 사이즈 질문은 `SIZE_GUIDANCE`로 분류해
`ASK_LIVE_SUBMIT` 이벤트를 남기며, 한 번의 질문만으로 개인 Need 감지 조건이 충족되지는 않는다.

`모델은 몇 사이즈 입었어?`, `아까 뭐라고 했어?` 등 영상 근거가 필요한 질문은 영상 미연결 안내를 우선한다.
이 질문에서 `사이즈`라는 단어만 보고 현재 고객에게 66을 추천하지 않는다.

후속 질문은 같은 고객·방송·상품의 마지막 지원 Intent를 참조한다. 대상이 불명확하면 확인 질문을 한다.
여러 질문은 지원 가능한 두 항목까지 각각 답하고, 지원하지 않는 부분은 분리해 안내한다.
근거 없는 설명·새로운 상품 특성·도착 확약을 생성하지 않는다.

## 응답과 실패

준비 답변은 인위적 지연 없이 반환할 수 있다. 외부 LLM을 붙일 경우 대기 상한을 5초로 두고
동일 Intent의 준비 답변으로 대체한다. 이는 이번 데모의 구현 기본값이며 운영 서비스 SLA가 아니다.
대체 답변을 표시한 뒤 늦게 도착한 원래 응답은 같은 request_id로 중복 삽입하지 않는다.
미지원 질문에는 해당 안내를 사용하고, 무관한 준비 답변을 끼워 넣지 않는다.

처리 상태만 표시한다. 배송은 `준비된 배송 안내를 확인하고 있어요`라고 표시하며
실제 배송 시스템이나 주소를 조회하는 것처럼 연출하지 않는다.

## 고객 상태와 영상 대체

사용자는 2026-09-21에 상품 이미지 기반 데모 진행, 영상 추후 연결을 선택했다.
기본 화면의 16:9 영역에는 실제 상품 이미지와 `상품 이미지 기반 데모` 라벨을 표시한다.
첫 이미지에서 시작하고 사용자가 이전·다음 버튼으로 전환한다. 재생 중인 방송 장면처럼 설명하지 않는다.
방송 시간이나 시청자 수를 표시한다면 별도의 시뮬레이션 값으로 표시한다.
영상 요약·검색·Bookmark·모델 착용정보는 비활성화하고 영상 확보 후 개별 검증한다.

화면 확장 전후에 대화, 진행 중인 요청, 고객, 상품, 선택 사이즈, 코디, 열린 결과와 이미지 위치를 유지한다.
회전·확장만으로 요청을 다시 보내거나 고객 행동 이벤트를 중복 발생시키지 않는다.

구매 버튼은 선택 옵션과 금액을 보여주는 `구매 시뮬레이션`으로 연결하며 실제 주문은 생성하지 않는다.
원본 링크는 별도 `실제 상품 보기`로 제공한다. 신발 사이즈 추천은 제공하지 않는다.

확인 시점에 메인 상품의 그레이 66 옵션은 실제 페이지에서 `일시품절`로 표시되었다.
준비된 사이즈 안내 66은 유지하되 구매 시뮬레이션에 해당 상태를 표시한다.
추천 사이즈가 실제 구매 가능 재고를 보장하는 것처럼 표현하지 않는다.

## 데이터 라벨

상품 페이지 확인값, 공개 리뷰 API에서 검증한 구매자 리뷰, 가상 프로필, 준비된 혜택, 배송 Mock,
AI Lookbook, Director Simulation은 `fixtures/demo-config.json`의 provenance와 라벨로 구분한다.
선택형 리뷰 5항목은 실제 API에서 확인했다. 제조사 두께 가이드와 구매자 리뷰가 다르므로
두께 답변에는 `구매자 리뷰 기준`을 표시한다. 리뷰 총수 1,200과 선택형 응답 합계 1,202의 차이는
데이터 원본대로 보존하고, 분모를 같다고 가정하거나 비율을 재계산하지 않는다.

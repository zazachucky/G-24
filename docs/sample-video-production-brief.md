# 쇼호스트 샘플 영상 제작 지시서

상태: **제작 준비본 — 최종 영상 미생성**.
사용자가 최종 선택한 형식은 실사형 가상 쇼호스트가 실제로 움직이며 설명하는 영상이다. 앞서 제시한 일러스트 스타일은 선택되지 않았다.
현재 환경에서 인물 영상 제작 연결은 관리자 설정으로 비활성화되어 있다.
본 지시서와 스토리보드를 허용된 영상 제작 도구에 전달해 렌더링한 뒤 검수한다.

## 길이와 구성

목표는 **2분 / 가로 16:9 / 1920×1080 / 30fps / 한국어**다.
상품·소재·사이즈 설명과 3개 코디를 담고, 장면 탐색·요약·중간 입장 시나리오에 쓸 구간을 확보한다.
10초씩 12개 구간으로 설계하되 최종 음성 속도에 따라 컷을 조정하여 120초에 맞춘다.
10초 구간은 계획 타임라인이며, 아직 측정된 최종 영상 타임스탬프가 아니다.

| 구간 | 설명 | 데모에서 사용할 수 있는 장면 |
| --- | --- | --- |
| 00:00–00:20 | 상품 소개·소재 | 상품명·소재 질문 |
| 00:20–00:40 | 색상·두께 리뷰 | 색상·두께 질문 |
| 00:40–01:00 | 사이즈 안내·선택 시 유의점 | 사이즈 설명 다시 보기 |
| 01:00–01:30 | 출근·약속·주말 코디 | 코디 추천과 상품 연결 |
| 01:30–01:50 | 가격·혜택·배송 | 실제 상품값과 데모값 구분 |
| 01:50–02:00 | 요약·안내 | Catch-up·요약 비교 |

## 영상 제작 도구에 전달할 공통 지시

```text
한국어로 상품을 설명하는 120초 분량의 가로 16:9 샘플 방송을 제작한다.
120초는 목표 길이이며, 장면별 10초는 편집 초안이다. 먼저 한국어 음성을 만든 뒤
발음이 자연스럽도록 컷 길이를 조정하고 최종 자막과 챕터 시각을 다시 맞춘다.
동일한 가상의 성인 쇼호스트 한 명과 같은 목소리를 모든 장면에서 유지한다.
인물은 실사형으로 표현한다. 자연스러운 피부·머리카락·의상 질감과 일관된 얼굴을 유지한다.
일러스트나 만화 스타일로 만들지 않는다. 정지 사진의 이동·확대만으로 인물 동작을 대신하지 않는다.
카메라는 상반신 중간 샷을 중심으로 하고 시선 이동, 고개 끄덕임, 손바닥을 펼치는
안내 동작 등 자연스러운 움직임을 넣는다. 발화와 입 모양을 일치시킨다.

쇼호스트는 로고 없는 중립적인 의상을 입는다. 출연자가 이 판매 상품을 직접 입거나
사용해 검증한 것처럼 말하지 않는다. 실제 인물의 얼굴·목소리를 복제하지 않는다.

쇼호스트 장면과 실제 상품 사진·실측표·코디 예시를 함께 배치한다.
상품을 설명할 때 쇼호스트가 화면의 자료 쪽으로 손을 가볍게 움직이도록 한다.
실제 상품 이미지는 제공된 원본을 사용하고 색상·치수·텍스트를 새로 생성하지 않는다.
AI 코디 이미지는 별도 예시로 표시하며 실제 판매 사진과 구분한다.
호스트 영상을 먼저 만든 뒤 실제 이미지·표·가격·자막을 별도 편집 레이어로 삽입한다.
문자와 숫자를 영상 생성 모델에 직접 그리게 하지 않는다.

아래 스토리보드의 narration만 한국어로 말한다. 없는 착용 후기, 재고, 할인율,
배송 확약, 모델 착용 사이즈를 즉흥적으로 추가하지 않는다.
장면마다 제공된 title, caption_lines, label을 반영한다.
host_delivery의 동작과 product_visual의 이미지별 표시·필수 강조문구도 반영한다.

발음 기준: SJ와니는 '에스제이와니', 의류 55/66/77/88은 '오오/육육/칠칠/팔팔'.
49,900원은 '사만 구천구백 원', 45,515원은 '사만 오천오백십오 원'.
소재 85/10/5%는 '팔십오/십/오 퍼센트', 실측 45/61cm는 '사십오/육십일 센티미터'.
리뷰 63%는 '육십삼 퍼센트', 2~3영업일은 '이삼 영업일'로 읽는다.

상시 작은 표시: '데모용 샘플 영상 · 합성 쇼호스트 · 실제 방송 아님'.
코디 장면: 'AI 코디 예시'. 혜택 장면: '데모 혜택 예시'.
배송 장면: '배송 시뮬레이션'. 실제 상품값에는 '2026.09.21 확인 자료'를 표시한다.

배경음악은 사용하지 않는다. 한국어 발화와 자막을 명확히 들리고 읽히게 한다.
화면 하단 자막 안전영역을 유지하고 자료·가격·신발을 자막으로 가리지 않는다.
최종 납품은 H.264 MP4, AAC 음성, 동기화된 한국어 SRT/VTT, 최종 챕터 목록이다.
```

## 렌더링 후 검수

1. 최종 파일에 실제 움직이는 쇼호스트, 한국어 발화와 입 모양 일치가 있는지 확인한다.
2. 같은 인물·목소리·복장이 장면 사이에서 유지되고 손·얼굴에 눈에 띄는 오류가 없는지 확인한다.
3. 소재·리뷰·사이즈·가격 수치가 원본과 같고, 66 추천과 그레이 66 일시품절을 구분하는지 확인한다.
4. 코디·혜택·배송의 예시/시뮬레이션 라벨과 상시 합성 표시를 확인한다.
5. 120초 목표와 자막 동기화를 확인하고 실제 컷 타임스탬프로 챕터를 갱신한다.
6. Video AI는 완성된 영상의 실제 음성·장면을 입력하여 별도 검증한다. 사전 대본만으로 PASS 처리하지 않는다.

아직 MP4나 추출 Transcript는 없다. `planned-*` 파일이 있으면 계획용 자막·챕터이며 실제 영상에서 추출한 자료가 아니다.

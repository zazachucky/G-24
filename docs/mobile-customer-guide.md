# GS AI LIVE 고객용 모바일 안내

최신 고객용 모바일 요청을 기준으로 디자인과 상호작용을 개선했습니다. 기존 통합 앱의 상품 자료, 개인 상태, Director 연동을 재사용합니다. 초기 모바일 개선 완료 당시 **Python 113개, Chrome 359개 검사**가 통과했습니다. Chrome 결과는 신규 모바일 48개와 이번 코드에서 다시 통과한 기존 회귀 311개입니다. [요구사항별 검토](mobile-customer-goal-review.md), [모바일 검수 결과](evidence/mobile-customer-goal-verification.json), [코드·검사 완료 감사](evidence/mobile-customer-completion-audit.json)에 범위와 근거를 기록했습니다.


**후속 코디 배치 수정 완료.** 오피스·데이트·데일리 탭의 큰 이미지는 기존 전신 AI 코디 예시를 사용하고, 오른쪽 LOOK 1~3 자리에는 선택 코디의 상의·하의·신발 실제 상품을 표시합니다. 상품 사진은 해당 상품 상세로 연결하며 탭 선택을 바꾸지 않습니다. 관련 Chrome **164개(모바일 54 + 고객 51 + 통합 59)** 검사를 다시 통과했습니다. [후속 검수 결과](evidence/styling-products-verification.json). 이전 완료 감사는 이 배치 수정 전의 기록입니다.

## 실행

프로젝트 폴더에서 실행합니다. Python 3.9 이상이면 별도 패키지 설치나 API 키가 필요 없습니다.

```sh
python3 app/server.py
```

- 고객 화면: <http://127.0.0.1:8765/app/customer.html>
- Director: <http://127.0.0.1:8765/app/director.html>

두 화면을 같은 서버에서 열면 상태가 연결됩니다. 종료는 실행 터미널에서 `Ctrl+C`를 누릅니다. 고객 대화·장바구니·프로필·운영 기록은 메모리에 저장되므로 서버 재시작이나 Director의 Reset으로 초기화됩니다. 앱은 같은 컴퓨터의 localhost 시연용이며, 외부 기기 접속·인증·영구 저장은 연결하지 않았습니다.

기본 서버 8765를 최신 코드로 재시작하고 **2026-09-21 10:58:24 UTC**에 고객 세로형 390px·가로형 844px과 Director 4개 화면이 공통 RUN `c8fc3743a5234f349a4cb9fbf72df086`에 연결된 것을 확인했습니다. 가로 넘침·브라우저 예외·HTTP 오류가 없었고 입력·코디·구매 버튼도 가려지지 않았습니다. 재시작으로 이전 메모리 시연 기록은 초기화됐습니다. [기본 서버 실행 확인](evidence/mobile-customer-live-runtime.json)을 참조하세요.

## 화면과 사용 흐름

기본 진입은 세로형이며 방송 영역은 상품 이미지 미리보기입니다. 16:9 LIVE 영역 아래에서 상품명·판매가·혜택가·사이즈·상품상세를 확인합니다. 내 사이즈·코디 추천·내 혜택, 입력창과 구매 버튼을 화면 아래에 유지하면서 상품과 통합 대화를 탐색합니다.

영상 안의 **확장해서 보기**로 가로형을 선택합니다. 왼쪽에는 방송과 상품정보, 오른쪽에는 통합 대화와 빠른 질문·입력창을 배치합니다. **세로로 보기**로 돌아옵니다. OS 자동 회전만으로 전환하지 않으며, 하나의 DOM과 고객 상태를 사용해 대화·선택 사이즈·작성 중 질문·AI 처리 상태·선택 코디를 유지합니다.

디자인 기준은 배경 `#FFFFFF`, 본문 `#282933`, AI 포인트 `#7644CF`, AI 보조 배경 `#F6F2FC`, 혜택 강조 `#CE526C`입니다. 상품정보는 무채색으로 읽기 쉽게 정리하고, 코디 추천을 다른 빠른 기능보다 강조합니다. 상품 사진과 코디 이미지가 중심이 되도록 장식을 줄입니다.

### 녹화 영상 선택

상품 영역 아래의 **영상 선택**에서 **코어어센틱 녹화 참고 영상** 또는 **상품 설명 샘플 · 제작 대본**을 고릅니다. 이미지 모드에는 ‘재생할 영상을 선택하세요’가 표시됩니다. 선택하면 영상이 보이는 위치로 이동하며, **재생**을 눌러 시작합니다. 이미지 모드로 돌아간 뒤 같은 영상을 다시 선택할 수 있고, 파일 로딩에 실패한 경우에도 같은 영상을 골라 재시도할 수 있습니다. 참고 영상은 현재 판매 상품과 다른 코어어센틱 가디건임을 화면에 표시합니다.

영상 선택 후 정기 상태 조회가 선택값이나 옵션을 불필요하게 다시 쓰지 않는 것을 검증했습니다. [선택·재생 검수](evidence/media-selection-verification.json) 19개와 기존 영상 24개·통합 화면 59개, 총 102개를 통과했습니다. OS의 기본 선택 팝업 자체는 자동화 범위 밖이며 선택 이벤트 이후의 상태·가시성·실제 MP4 디코딩과 재생을 확인했습니다.

### AI 맞춤형 코디 추천

가상 고객 김지수의 초기 취향은 오피스입니다. 원하는 취향 탭을 선택하면 현재 방송의 그레이 니트를 기준으로 준비한 세 가지 코디와 추천 이유를 확인합니다.

| 취향 | 구성 |
| --- | --- |
| 오피스 | 그레이 니트 + 아이보리 슬랙스 + 블랙 로퍼 |
| 데이트 | 그레이 니트 + 브라운 계열 스커트 + 아이보리 메리제인 |
| 데일리 | 그레이 니트 + 블루 와이드 데님 + 아이보리 스니커즈 |

오피스·데이트·데일리 탭은 기존 LOOK 1~3의 전신 코디 이미지를 큰 **AI 코디 예시**에 표시합니다. 오른쪽의 기존 LOOK 1~3 자리에는 현재 코디의 **상의·하의·신발 실제 상품 사진**이 들어갑니다. 탭을 바꾸면 상품 구성도 함께 바뀌며, 상품 사진을 누르면 해당 상품 상세가 새 창으로 열립니다. 상품 클릭으로 선택한 취향은 바뀌지 않습니다.

이미지는 사전 생성한 정적 파일이며 **AI 코디 예시**로 표시합니다. 클릭할 때 이미지를 생성하지 않습니다. 실제 상품 사진·가격·링크는 별도 카드에 표시하고, 공개 상품 페이지와 이미지를 확인해 사용 대상으로 확정한 상품만 연결합니다. 준비된 코디 이미지의 옷이 실제 상품과 완전히 동일하다고 설명하지 않습니다.

신발은 디자인·색상·스타일만 추천합니다. 상의 66을 하의·신발에 적용하지 않으며 신발 사이즈를 추천하지 않습니다. 실제 재고·가격·혜택은 연결한 GS SHOP 상품 페이지에서 다시 확인해야 합니다.

### 내 사이즈와 내 혜택

기본 프로필은 가상 고객 김지수, 평소 상의 66입니다. 상품 옵션은 55·66·77·88이고, 기본 안내는 **“66 사이즈를 먼저 확인해보세요.”**입니다. 상품 전체 사이즈 리뷰의 ‘잘 맞아요’는 87%입니다. 특정 체형 집단의 만족률이나 가상의 개인 후기를 만들지 않습니다.

반사이즈에 걸치면 한 사이즈 크게 확인하도록 안내합니다. 선택 입력에서 보유 의류의 가슴단면과 상품의 실제 실측표를 비교할 수 있지만, 키만으로 신체 치수나 착용 사이즈를 추정하지 않습니다. 자료에 없는 모델 착용 사이즈도 만들지 않습니다. 추천 결과를 저장해도 현재 구매 옵션을 자동 변경하지 않습니다. **실제 사이즈표 확인하기**와 **구매 시뮬레이션**으로 이어집니다.

그레이 66은 채택한 상품 스냅샷에서 일시품절입니다. 기본 추천과 주문 가능 여부는 별도로 표시하며, 구매 체험에서는 확인 당시 품절 표시가 없는 옵션을 선택합니다.

| 혜택 항목 | 금액 |
| --- | ---: |
| 기본 가격 | 49,900원 |
| VIP 5% 할인 | −2,495원 |
| VIP GS Pay 할인 | −1,890원 |
| 총 할인 | −4,385원 |
| 최종 혜택가 | 45,515원 |

혜택은 가상 VIP·GS Pay 조건으로 준비한 계산 예시입니다. 실제 회원 등급·결제수단·쿠폰을 조회하지 않으며, 추가 혜택 안내를 할인 금액에 중복 합산하지 않습니다.

### 통합 대화와 선제 제안

운영자·고객·ASK LIVE 발화를 같은 타임라인 안에서 구분합니다. 상품후기·두께감·색상·배송일정의 빠른 질문과 자유 입력을 지원합니다. 준비 중에는 “구매후기를 확인하고 있어요” 같은 진행 상태만 표시합니다. 근거 있는 준비 답변을 제공하고, 자료에 없는 질문은 확인 한계와 상품문의 경로를 안내합니다. 배송 예정 안내는 **배송 시뮬레이션**입니다.

화면 아래의 입력창에서 질문을 제출하면 같은 고객·상품의 통합 대화로 스크롤해 응답이나 진행 상태를 보여줍니다. 작성 중인 다음 질문은 유지합니다. 상태 조회나 방향 전환만으로 대화 위치를 강제로 옮기지 않고, 다른 고객으로 전환했거나 결과 창을 열었으면 늦은 요청이 화면을 이동시키지 않습니다.

개인 ASK 질문과 사이즈 입력은 해당 고객에게만 표시합니다. 운영자 안내는 공용이며, 별도 공개 댓글 입력에 제출한 내용만 다른 고객과 Director에 공개됩니다.

최신 선제 제안 조건은 같은 고객·방송·상품에서 **30초 이내 사이즈 관련 행동 2건**입니다. 사이즈표 조회 → 사이즈 리뷰 확인 또는 사이즈표의 별도 재조회 → 재조회처럼 같은 종류도 포함합니다. 정확히 30초는 포함하고, 동일한 `event_id`를 재전송한 요청은 두 번 세지 않습니다. 이 규칙이 이전 문서의 ‘서로 다른 2종’ 조건을 대체합니다.

- 감지하면 “사이즈가 고민되시나요?”라는 작은 제안을 표시합니다.
- **확인하기**를 누를 때만 내 사이즈 결과를 엽니다.
- **괜찮아요**를 누르면 같은 방송의 같은 제안을 다시 표시하지 않습니다.
- 거절해도 직접 **내 사이즈**를 열 수 있습니다.

## 검수

앱 실행과 달리 브라우저 검수에는 Node.js와 설치된 Chrome이 필요합니다. 검사 전용 서버를 별도 터미널에서 띄웁니다. 아래 모바일 검사는 전용 서버 상태를 초기화하므로 사용자 시연 서버 8765를 대상으로 실행하지 않습니다.

```sh
python3 app/server.py --port 8795
```

다른 터미널에서 실행합니다.

```sh
python3 -m unittest discover -s tests -v
GS_MOBILE_URL=http://127.0.0.1:8795 node scripts/check_mobile_customer_goal.cjs
```
